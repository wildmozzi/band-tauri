# GOAL — SYNCROOM 수준의 실시간 합주

**한 문장 목표:** 같은 나라 안의 연주자 최대 6명이 데스크톱 앱으로 접속해, 끊김 없이 박자를 맞춰 1시간 이상 합주할 수 있다. 웹 사용자는 그 합주를 관람한다.

모든 작업은 아래 기준을 하나라도 앞당기는지로 우선순위를 정한다. 기준을 측정할 수 없는 항목은 먼저 측정 수단을 만든다.

## 1. 지연 (Latency)

| 지표 | 목표 | 측정 방법 |
|---|---|---|
| 로컬 처리 지연 (`estLatencyMs`, 입력 버퍼+프레임+출력 링+출력 버퍼) | ASIO 128샘플/2.5ms 프레임: **≤ 8ms**, WASAPI 독점: **≤ 15ms**, WASAPI 공유: ≤ 30ms | 엔진 통계 + 루프백 측정 도구 |
| 입→귀 총 지연 (상대 연주자 소리가 내 귀에 도달) | 같은 도시(RTT ≤ 10ms) **≤ 25ms**, 국내 원거리(RTT ≤ 30ms) **≤ 40ms** | 에코 피어 모드로 왕복 클릭 측정 ÷ 2 |
| 지터 버퍼 추가 지연 | 안정 회선에서 중앙값 ≤ 1프레임 + p95 지터 | `PeerStats.bufferMs` |
| 지연 누적 | 60분 동안 `bufferMs`가 목표 ±3ms 밖으로 1분 이상 머무르지 않음 | 드리프트 ±200ppm 장시간 테스트 |

## 2. 안정성 (끊김 없음)

| 지표 | 목표 |
|---|---|
| 손실 1% 회선에서 은닉 프레임 비율 | ≤ 1.5%, 청감상 끊김 없음(Opus PLC/FEC) |
| 기본 프리셋 xrun | 30분 동안 0회 (일반 사양 PC, WASAPI 독점) |
| 6인 풀메시 | 60분 연속, CPU ≤ 15%(4코어 기준), 피어 재연결 없이 유지 |
| 일시적 단절 | WS 30초 이내 재연결 시 오디오 끊김 없음(세션 재개), UDP 경로 5초 단절 후 자동 복구 |

## 3. 연결성

| 지표 | 목표 |
|---|---|
| 직접 연결 성공률 | 일반 가정용 공유기(콘형 NAT) 쌍 **100%**, 같은 공유기 내 LAN 우선 연결 |
| 직접 연결 실패 시 | **UDP 릴레이 서버**로 자동 폴백(지연 증가를 UI에 표시) — 대칭형 NAT/LTE 포함 연결 성공률 ≥ 98% |
| 연결 소요 시간 | 입장 후 3초 이내 소리 들림 |

## 4. 사용성 (SYNCROOM 기본 기능 대응)

- 오디오 인터페이스 선택(ASIO/WASAPI), 입력 채널 선택, 버퍼/품질 프리셋, 입력 모니터
- 멤버별 볼륨/뮤트/패닝, 멤버별 지연·회선 품질 표시, 내 입력 레벨 미터
- 방 생성/비밀번호/공개 여부, 연주 참여 승인
- 합주 녹음(멀티트랙 또는 믹스), 공유 메트로놈(지연 보정)
- 설치 파일(코드 서명), 자동 업데이트, 문제 발생 시 로그 내보내기

## 5. 품질 게이트 (모든 PR)

- CI 통과: Rust `clippy -D warnings` + `cargo test`, client build + vitest, server build + test
- 실시간 경로(`engine/rt.rs`)에 할당/락/시스템콜/로그 추가 금지
- 새 기능은 테스트 동반. 엔진 변경은 루프백 테스트의 지연·은닉 수치를 PR에 기록
- 실제 장비/실네트워크가 필요한 검증은 PR과 백로그에 **[사람 확인]**으로 표시하고 사용자에게 절차를 안내
